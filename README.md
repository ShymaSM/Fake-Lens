# 🛡️ DeepGuard AI — Deep Fake Detection Using AI

**DeepGuard AI** is a modern and interactive web application designed to demonstrate how Artificial Intelligence and Machine Learning can be used to identify potentially manipulated images and videos.

The project focuses on improving digital safety, reducing misinformation, and building trust in online media.

## 🎯 Project Objective

Deepfake technology can create realistic fake images, videos, and audio. These manipulated media can be used for misinformation, online fraud, scams, and social media manipulation.

DeepGuard AI aims to provide an easy-to-use platform where users can upload media and understand how AI-based systems can analyze and classify digital content as **Real** or **Potentially Fake**.
